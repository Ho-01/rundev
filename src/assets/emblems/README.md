# Pixel tier emblems

선택한 FORGED CIRCUIT 보석 세공 시안을 이미지 생성 도구로 도트 스타일로 변환했다.
보석과 같은 재질로 새긴 티어별 고유 아이콘, 금속 프레임과 3단계 장식 성장을 유지한다.

`source/approved-tier-board.png`는 승인된 3열 × 10행 최종 시안이다.
1단계는 짧은 옆 장식, 2단계는 위로 꺾인 날개, 3단계는 넓게 펼친 날개와
상단의 분리된 금속 장식을 사용한다. 티어 순서는 `src/domain/level.ts`와 같다.
`source/pixel-tier-atlas.png`는 이전 디자인의 참고 원본으로 유지한다.

`node scripts/build-tier-emblems.mjs`로 `pixel/<tier>-<stage>.png` 30개를 생성한다.
각 파일은 실제 외곽에 맞춰 자른 투명 팔레트 PNG다. 라벨을 제외한 세 열에서
외부와 연결된 어두운 배경을 제거하고, 연결 영역을 티어 행에 대응한다.
보석 내부의 어두운 색과 분리된 상단 장식까지 보존하며, 전체 외곽을 함께 추출한다.
공통 배율로 64×64 작업 캔버스에서 정렬한 뒤, 표시용 PNG에서는 불필요한 투명 영역을
잘라내고 실제 외곽 주위에 사방 2px만 남긴다. UI는 각 파일의 실제 크기와 공통
0.9 배율로 표시한다. 배정 영역에 맞춰 개별 확대·축소하지 않으므로 날개가 넓어져도
보석 본체가 작아지지 않는다. 모든 티어는 최대 장식 크기를 담는 54×44 영역을 공유한다.
알파 외곽을 좌우 대칭으로 보정한다. 중앙 24×24 아이콘 영역은 유지하고 그 밖의
프레임 픽셀은 좌우를 동일하게 맞춘다. 망치 등 중앙 상징의 의도된 비대칭은 보존한다.
원본 추출 좌표와 최종 투명 여백 제거 좌표는 `source/extraction.json`에 기록한다.
렌더링에는 `image-rendering: pixelated`를 적용하고 필요한 이미지 URL만 사용한다.
작은 PNG도 JS에 인라인으로 포함되지 않도록 URL import에 `no-inline`을 지정한다.

`node scripts/check-tier-emblems.mjs`로 30개 전체의 크기·투명도·좌우 외곽 및 프레임 대칭·
중앙 정렬·정확히 2px인 여백 및 레전드 3단계의 확장 여부를 검증한다.

생성 프롬프트 요약: 승인된 30개 보석형 엠블럼을 동일한 아이콘과 장식 성장으로
유지하면서 16비트 도트 스타일, 선명한 픽셀 클러스터, 제한된 재질별 명암으로
변환한다. 텍스트와 배경은 제거하고 실제 알파 투명도를 가진 동일 간격의 6×5
스프라이트 시트로 출력한다. 티어별 아이콘은 새싹·망치·코드·버그·터미널·네트워크·
CPU·워크플로·체크·왕관이며 보석과 같은 색의 양각/음각 질감을 유지한다.
