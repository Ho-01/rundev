FAQ

자주 묻는 질문

설치 전에 알아둘 내용을 모았습니다.

어떤 운영체제를 지원하나요?

Windows와 Apple Silicon·Intel macOS를 지원합니다. 최신 설치 파일은 GitHub Releases에서 받을 수 있습니다.

키보드에 입력한 내용을 읽나요?

아니요. 키 입력 내용은 읽거나 저장하지 않고 누른 횟수만 집계합니다. 프롬프트, 응답, 소스 코드도 수집하지 않습니다.

RunDev 계정이 필요한가요?

필요하지 않습니다. RunDev 서버 계정 없이 로컬에서 동작합니다. AI 도구 연동도 사용자가 선택할 때만 이루어집니다.

무료인가요?

현재 빌드는 GitHub Releases에서 받을 수 있습니다. 향후 Steam 제품화 정책은 출시 준비와 함께 안내할 예정입니다.
