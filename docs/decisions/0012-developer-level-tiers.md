# 0012. 개발자 레벨을 열 개 등급의 성장 배지로 표현

- 상태: Accepted
- 날짜: 2026-07-29

## 맥락

기존 개발자 상태는 흰 원 안의 숫자와 XP 진행률만 보여주어 레벨 상승의 시각적
차이가 작았다. 캐릭터 선택과 별개로 활동 XP가 쌓여 성장한다는 느낌을 주면서도
작은 트레이 팝오버에 맞는 표현이 필요하다.

## 결정

- 100 XP마다 기존 방식대로 레벨이 1 증가한다.
- 레벨 구간을 다음 열 개 등급으로 표현한다.
  - Lv.1–4: 새싹 개발자
  - Lv.5–9: 루키 빌더
  - Lv.10–19: 코드 메이커
  - Lv.20–34: 디버거
  - Lv.35–49: 코드 해커
  - Lv.50–69: 시스템 설계자
  - Lv.70–99: 아키텍트
  - Lv.100–149: 테크 리드
  - Lv.150–249: 마스터 개발자
  - Lv.250 이상: 레전드 개발자
- 왼쪽에는 숫자만 담은 네모 대신 등급 전용 엠블럼을 표시하고, 등급명 오른쪽에
  `Lv.숫자` 라벨을 둔다. 등급마다 배지 색상과 아이콘을 바꾸고 XP 진행 막대에도
  같은 강조색을 사용한다.
- 등급 규칙은 `src/domain/level.ts` 한 곳에서 관리한다.
- README 미리보기는 실제 앱과 같은 React 컴포넌트와 등급 규칙을 렌더링해 자동
  생성한다.

## 결과

### 장점

- 레벨 상승과 장기 성장 단계가 즉시 구분된다.
- 캐릭터 애셋을 추가하지 않고도 등급별 개성을 표현할 수 있다.
- 앱과 README가 같은 구현을 사용하므로 문서 이미지가 실제 UI와 어긋나지 않는다.

### 단점

- 레벨 구간이나 명칭 변경은 사용자에게 보이는 성장 체계 변경이 된다.
- 등급 수가 늘어 초반 등급의 체류 시간이 짧게 느껴질 수 있다.

## 대안

- 레벨마다 별도 이미지를 제작하는 방식은 애셋 관리 비용이 커 선택하지 않았다.
- 숫자 배지의 색만 바꾸는 방식은 등급 차이가 충분히 드러나지 않아 선택하지 않았다.
