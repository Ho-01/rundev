# 0005. 개인정보 최소 수집

- 상태: Accepted
- 날짜: 2026-07-28

## 맥락

개발 활동 측정은 쉽게 키 입력, 창 제목, 소스 코드, 프롬프트 원문 수집으로 확장될
수 있다. 이는 제품의 핵심 가치에 비해 개인정보 위험이 크다.

## 결정

MVP는 다음 데이터만 수집한다.

- 활성 앱의 분류
- 활동/유휴 시간
- 화면 잠금 여부
- 사용자가 연결한 AI 도구의 집계 사용량과 신뢰도

다음 데이터는 수집하지 않는다.

- 실제 키 입력
- 창 또는 문서 본문
- 소스 코드
- 프롬프트와 응답 원문
- 화면 캡처와 클립보드

macOS Accessibility 권한은 기능에 반드시 필요한 시점에만 요청한다. 새로운 데이터
종류를 추가하기 전에 별도의 ADR과 사용자 설정을 설계한다.

## 결과

### 장점

- 데이터 유출 영향을 최소화한다.
- 권한 요청과 사용자 설명이 단순해진다.
- 로컬 우선 제품 약속을 명확하게 유지한다.

### 단점

- 프로젝트별 또는 언어별 정밀 분석이 제한된다.
- 일부 AI 도구 사용량의 정확도가 낮을 수 있다.

## 대안

- 창 제목 기반 프로젝트 탐지
- IDE 플러그인으로 편집 내용 수집
- 원격 텔레메트리 기반 분석
