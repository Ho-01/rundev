# ADR 0044: AI 토큰 XP 적립 종료

- 상태: Accepted
- 날짜: 2026-11-17
- 대체: ADR 0037의 AI 토큰 마일스톤 보상

## 결정

AI 사용량은 계정 한도 사용률과 초기화까지 남은 시간을 표시하는 기능으로 유지한다.
토큰 수에 따른 XP 서비스, 동기화 command와 주간 XP UI를 제거한다.
한도 비율과 급여 예상액도 XP로 환산하지 않는다.

이미 지급한 XP와 `xp_events` 원장, 기존 AI 마일스톤 테이블은 이력으로 보존한다.
새 AI 마일스톤의 지급은 공통 XP 서비스에서도 거부한다.

AI 보상 전용 `context-runner` 특성은 더 이상 제공하거나 강화하지 않는다.
기존 레벨 데이터는 보존하지만 활성 특성 및 사용 포인트 합계에서 제외하므로,
해당 특성에 투자했던 포인트는 자동으로 다시 사용할 수 있다. 스키마 변경은 없다.

주간 AI XP 영역은 예상 급여 요약으로 대체한다. 개발 시간·키 입력은 제목과
수치를 한 줄에 표시하고 보상 진행률은 그 아래에 유지한다.
