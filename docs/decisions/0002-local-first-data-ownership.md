# 0002. Rust가 로컬 데이터를 소유

- 상태: Accepted
- 날짜: 2026-07-28

## 맥락

개발 활동과 AI 사용량은 민감할 수 있다. MVP에는 계정, 동기화, 랭킹이 필요하지
않으며 프론트엔드가 DB를 직접 수정하면 XP 조작과 스키마 결합이 쉬워진다.

## 결정

- 모든 사용자 데이터는 앱 데이터 디렉터리의 SQLite에 저장한다.
- Rust service만 DB에 접근한다.
- React는 타입이 지정된 Tauri command를 통해 조회하거나 동작을 요청한다.
- 로그인, 원격 서버, 텔레메트리는 추가하지 않는다.
- Updater는 서명키와 배포 endpoint가 준비된 이후 별도 ADR로 활성화한다.

## 결과

### 장점

- 오프라인에서 모든 핵심 기능이 동작한다.
- 데이터가 기기 밖으로 나가지 않는 기본값을 제공한다.
- DB 변경과 무결성 규칙을 Rust 경계 안에서 관리할 수 있다.

### 단점

- 여러 기기 사이 동기화가 없다.
- 기기 손실 시 자동 복구가 불가능하다.
- 향후 서버 도입 시 충돌 해결과 마이그레이션 설계가 필요하다.

## 대안

- Tauri SQL 플러그인을 통한 프론트 직접 접근
- 초기 버전부터 Supabase/PostgreSQL 사용
