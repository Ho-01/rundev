# 0004. 이벤트 원장 기반 XP

- 상태: Accepted
- 날짜: 2026-07-28

## 맥락

XP 규칙은 제품 성장에 따라 바뀔 수 있고 동일 활동 이벤트가 중복 수집될 수 있다.
캐릭터의 합계만 저장하면 어떤 활동으로 XP가 증가했는지 추적하거나 재계산하기
어렵다.

## 결정

- 모든 XP 변화는 `xp_events`에 불변 이벤트로 기록한다.
- `event_type`, `amount`, `source_event_id`, 발생 시간을 보존한다.
- `source_event_id`가 있는 이벤트는 유일성 제약으로 중복을 방지한다.
- `character_state`는 빠른 조회를 위한 파생 상태로 취급한다.
- 규칙 버전이 필요해지면 새 migration과 ADR로 추가한다.

## 결과

### 장점

- XP 증가 원인을 감사할 수 있다.
- 중복 이벤트를 탐지할 수 있다.
- 규칙 변경 시 재계산 기반을 제공한다.

### 단점

- 합계만 저장할 때보다 레코드 수가 많아진다.
- 원장과 파생 상태의 원자적 갱신이 필요하다.

## 대안

- `character_state.total_xp`만 직접 증가
- 매번 전체 활동 세션에서 XP 계산
