# ADR 0042: 로컬 예상 급여 카운터

상태: 채택

## 결정

사용자가 직접 입력한 월 급여(원), 매월 급여일, 출퇴근 및 점심 시작·종료 시각,
하루 순근무시간과 근무 요일을 로컬 SQLite `app_settings`의 `salary.settings`에
저장한다. 자동 수집, 서버 전송, 진단 로그 기록은 하지 않는다. 설정 삭제를 제공한다.
급여 데이터는 암호화하지 않은 기존 앱 DB에 저장되므로 기기 접근 권한을 가진
사용자는 읽을 수 있다. XP나 활동 수집과 연결하지 않는다.

Rust 도메인이 검증과 계산을 소유하며 서비스가 저장을 담당한다. React는
`src/services/salary.ts`를 통해 매초 Rust의 스냅샷을 받아 원화로 표시한다.
설정 전에는 계산하지 않는다. 브라우저 미리보기에서는 저장·계산을 지원하지 않는다.

## 계산 규칙

근무 중 매초 캐릭터 중앙에서 동일한 스냅샷의 초당 증가액이 흰색으로 나타나
위로 떠오르며 사라진다. 점심·퇴근 후에는 효과를 생성하지 않는다. 플로팅 모드는 별도의
투명·비활성·마우스 통과 창 `character-salary`에 오늘 누적액 말풍선을 표시한다.
Rust가 캐릭터 창의 위치·크기·모니터를 따라 배치하고 캐릭터 숨김이나 설정 삭제 시
함께 숨긴다. 기존 캐릭터 창의 크기, 드래그 및 이동 판정 영역은 유지한다.
설정 변경은 값 없이 이벤트로 알린다. 말투는 현재 모든 캐릭터에 동일하게 적용한다.

- 로컬 달력·시계 기준으로 직전 급여일 00:00부터 다음 급여일 00:00 미만까지
  한 주기로 삼는다. 급여일 당일 00:00에 누적액이 초기화된다.
- 29~31일이 없는 달은 말일을 사용한다. 휴일에 따른 급여일 이동은 하지 않는다.
- 주기 내 선택된 근무 요일의 순근무 초 전체로 월 급여를 균등 분배한다.
- 출근 전·점심·퇴근 후·비근무일에는 증가하지 않는다. 하루 순근무시간은
  출퇴근 간격에서 점심을 제외한 시간과 일치해야 한다.
- 같은 날 끝나는 근무만 지원한다. 야간 교대, 공휴일, 휴가, 초과근무, 세금,
  주휴수당 및 회사별 정산 규정은 반영하지 않는 시각적 예상액이다.
- 앱이 꺼져 있어도 재실행 시 설정과 현재 시각으로 재계산한다. 금액 원장은
  만들지 않으며 설정·기기 시간대 변경 시 현재 주기 전체에 새 기준이 적용된다.
- 월 급여는 사용자가 보고 싶은 세전 또는 세후 금액을 입력한다.
