# ADR 0045: 내용 높이에 맞추는 트레이 창과 AI 상세 오버레이

- 상태: Accepted
- 날짜: 2026-11-17
- 보완: ADR 0038

## 결정

React는 정상 흐름의 대시보드 내용 높이를 ResizeObserver로 측정하고, 서비스로
캡슐화한 `set_main_window_content_height` command에 논리 픽셀 높이를 전달한다.
Rust가 DPI 변환, 모니터 작업 영역 제한, 실제 창 크기와 위치를 소유한다.
우측 요약 고정과 좌우 상세 패널을 전환할 때도 마지막 측정 높이를 유지한다.
작업 영역 안에 들어오는 일반 화면은 본문 스크롤과 하단 빈 공간이 생기지 않는다.
아주 작은 작업 영역에서는 창을 화면 안으로 제한하고 본문 이동을 허용한다.

AI 상세는 하나만 열리는 fixed 오버레이로 표시한다. 행 위치를 기준으로 창 안에
배치하며 본문 높이에는 포함하지 않는다. 바깥 클릭과 Esc로 닫을 수 있다.
긴 상세와 급여 설정 모달은 스크롤 동작을 유지하되 스크롤바는 숨긴다.
모달이나 AI 상세를 열어도 기본 창 높이는 변하지 않는다.
