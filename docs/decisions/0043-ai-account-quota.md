# ADR 0043: AI 계정 한도 사용률 표시

- 상태: Accepted
- 날짜: 2026-11-17

## 배경

일별 토큰 집계와 계정 한도 사용률은 다른 지표다. Codex 일별 집계는 지연될 수 있고,
Claude OpenTelemetry는 수집기를 향해 전송된 이벤트만 집계하므로 다른 실행 환경의
계정 전체 사용량을 대체하지 못한다.

## 결정

명시적으로 연결된 AI 제공자에 한해 사용률, 한도 기간, 초기화 시각과 조회 상태를
Rust에서 조회한다. Codex는 설치 CLI의 `account/rateLimits/read`, Claude는
기존 Claude Code 로그인 자격 증명으로 Anthropic의 계정 사용량 API를 읽는다.
Claude API는 공개 안정성 계약이 없는 경로이므로 응답 변경과 인증 실패를 별도로 처리한다.
Cursor는 기존 동의 및 조회 경로의 plan 사용률을 재사용한다.

Claude 자격 증명은 설정 디렉터리 또는 macOS Keychain에서 읽고 제공자 요청에만 사용한다.
RunDev DB/프론트엔드/로그에 자격 증명과 원본 응답을 저장하지 않는다. 로그인 정보를
갱신하거나 타 앱 설정을 수정하지 않는다. 프롬프트, 응답, 소스 코드, 세션 원문은 읽지 않는다.

한도 스냅샷은 메모리에만 유지한다. 일반 조회는 60초 이상 간격을 두며 429는 5분
간격으로 재시도한다. 실패 시 마지막 정상 값을 유지하되 갱신 실패를 명시한다.
연결 해제 시 표시하지 않는다. 사용률을 토큰 수나 XP로 변환하지 않는다.
React는 Rust 스냅샷을 표시하고 초기화까지 남은 시간만 계산한다.
