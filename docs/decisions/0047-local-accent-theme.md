# 0047: 로컬 강조색 테마

- 상태: 승인
- 날짜: 2026-11-18

## 결정

앱 메뉴의 색상 테마 모달에서 기존 기본 그린과 후보 12색을 선택한다.
Rust `appearance` 모듈이 허용된 테마 ID를 검증하고 기존 SQLite
`app_settings`의 `appearance.accent_theme`에 저장한다. 새로운 수집 항목이나
외부 통신은 추가하지 않는다. 누락되거나 알 수 없는 ID는 기본 그린으로 표시한다.

React 서비스는 Tauri command를 통해 설정을 읽고 저장한다. localStorage는
첫 화면의 깜빡임을 줄이는 캐시이며 네이티브 앱의 설정 원본은 SQLite다.
테마 모달은 열 때만 로딩하고, 미리보기는 현재 창에만 적용한다. 적용하면 저장 후
`accent-theme-changed` 이벤트로 열린 창을 갱신한다. 취소하면 원래 색을 복원한다.

## 결과

CSS 변수로 고정 버튼, 급여 숫자, 컬렉션 선택 등의 강조색을 공유한다.
근무 상태와 오류 등 의미가 있는 상태색은 테마 변경 대상에서 제외한다.
창이 폐기되거나 앱이 재실행되어도 저장된 테마를 다시 읽는다. 테마 동기화에
주기적인 타이머나 별도 웹뷰를 추가하지 않는다.
