# 0016. Cursor 사용량은 명시 동의 후 비공식 Dashboard API로 조회

- 상태: Accepted
- 날짜: 2026-07-29

## 배경

Cursor 개인 계정은 사용량을 조회하는 공식 공개 API를 제공하지 않는다. Cursor 앱은
로컬 `state.vscdb`에 로그인 세션을 저장하고, cursor.com Dashboard는 이 세션으로
현재 주기 한도와 계정 사용량을 조회한다.

RunDev는 Cursor의 프롬프트, 응답, 채팅 및 소스 코드를 읽지 않으면서 사용자가 자신의
사용량을 한 화면에서 확인할 수 있어야 한다.

## 결정

- 기능은 기본 비활성이며 사용자의 명시 동의 전에는 Cursor 인증정보를 읽거나 외부
  요청을 보내지 않는다.
- 동의 후 OS별 Cursor `globalStorage/state.vscdb`를 read-only로 열고
  `cursorAuth/accessToken` 키 한 개만 읽는다.
- 토큰으로 `cursor.com`의 계정 확인, 오늘 집계, 현재 주기 한도만 조회한다.
- 토큰, 쿠키, 원본 응답, 원본 이메일은 RunDev DB에 저장하거나 로그에 남기지 않는다.
- 계정은 Cursor 사용자 ID의 SHA-256 `account_key`와 마스킹된 이메일로만 구분한다.
- 상세 사용 이벤트는 오늘 요청·토큰 합산에만 일시적으로 사용하고 원본은 저장하지
  않는다.
- 자동 동기화는 5분 간격이며 팝오버를 열 때 마지막 요청 후 60초가 지났으면 Codex와
  Cursor를 병렬로 갱신한다.
- redirect를 허용하지 않고 `https://cursor.com` 고정 endpoint만 사용한다.

## 위험과 대응

이 연동은 Cursor가 공개하거나 지원하는 API가 아니다. 응답이나 인증 방식이 변경될
수 있고, Cursor 약관의 데이터 추출 제한과 충돌할 가능성이 있다. RunDev는 Cursor와
제휴하거나 승인받은 제품이 아니며, 401·429·알 수 없는 응답 형식에서는 기존
스냅샷을 보존하고 안전하게 동기화를 중단한다.

공식 개인 사용량 API가 제공되면 비공식 경로를 폐기하고 공식 API로 전환한다.

## 제외

- 브라우저 쿠키 저장소 탐색
- workspaceStorage 및 채팅 DB 탐색
- 요청별 이벤트 원장과 모델별 내역
- XP 지급
- Team Admin API
- 토큰 환경변수 override

## 요청 기반 사용량 보정

팀의 요청 기반 플랜에서 `individualUsage.plan.used/limit`은 달러가 아니라 센트
환산 크레딧이다. RunDev는 요청당 4센트 기준으로 포함 요청 수를 표시한다.
오늘의 요청 수와 토큰 총량은 상세 이벤트를 메모리에서 집계하되 개별 이벤트,
대화 식별자, 모델명은 영속화하지 않는다. 온디맨드 금액은 해당 기능이 활성화된
경우에만 별도 금액으로 표시한다.
