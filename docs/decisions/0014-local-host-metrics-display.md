# 0014. 로컬 호스트 지표의 표시 전용 수집

- 상태: Accepted
- 날짜: 2026-07-29

## 맥락

RunCat 계열 트레이 유틸은 CPU·메모리·저장 공간·배터리·네트워크를 한눈에
보여 준다. RunDev도 CPU·메모리·온도·디스크·배터리·네트워크를 팝오버 오른쪽 sticky strip에
표시하려 한다.
이 값은 활동 XP나 원장과 무관하며, ADR 0005의 최소 수집 범위를 넘기므로 별도
결정이 필요하다.

## 결정

- 목적: 트레이 팝오버에서 실시간으로만 표시한다.
- 디스크·SQLite·원장에 호스트 지표를 저장하지 않는다.
- 프로세스 메모리에는 최신 스냅샷 1개와 CPU/네트워크 차분용 baseline만 둔다.
- 허용 필드: CPU 사용률(%), 메모리 사용률(used/total %, macOS Memory Pressure 아님),
  CPU/SoC 온도(°C, 센서 없으면 null), 주 볼륨 디스크 점유율(%), 배터리 잔량·상태(없으면
  null), 네트워크 송수신 속도(byte/s). 온도는 표시용 숫자만 두고 센서 이름은 저장·로그하지
  않는다.
- 네트워크는 sysinfo가 반환하는 어댑터 합산 “네트워크 활동”이다. VPN·가상
  NIC·loopback으로 중복되거나 인터넷 실사용과 다를 수 있음을 UI/문서에 고지한다.
- 금지: 연결 목록, SSID, IP, MAC, 인터페이스명, 프로세스별 트래픽, 목적지,
  지표 payload를 일반 로그·crash report에 남기기.
- 수집기는 앱 수명 동안 HostMetricsService 하나다. 창 재오픈으로 루프를 추가
  생성하지 않는다.
- 샘플 주기: CPU·메모리·네트워크 1초, 온도 5초, 디스크 30초, 배터리 15초. emit은 1초.
- strip 숨김 설정과 default-route만 측정하는 네트워크는 후속이다.

## 결과

### 장점

- RunCat과 같은 지표 세트를 로컬에서만 보여 줄 수 있다.
- XP·활동 데이터와 경계를 유지한다.
- Windows와 macOS를 공통 sysinfo 경로로 맞출 수 있다.

### 단점

- 네트워크 합산은 “인터넷 속도”와 다를 수 있다.
- 메모리 사용률은 macOS Memory Pressure와 다르다.
- 1초 샘플은 잘못된 `refresh_all` 구현 시 부하가 커질 수 있다.

## 대안

- 전용 업데이트/메트릭 서버 — 로컬 우선과 맞지 않아 선택하지 않았다.
- default-route 네트워크만 측정 — 플랫폼별 구현 비용이 커서 후속으로 남겼다.
