# 0020. 프로바이더 통합 주간 AI 사용 XP

- 상태: Superseded
- 날짜: 2026-08-04
- 대체: [ADR 0037](0037-trait-economy-and-ai-xp-rebalance.md)

## 맥락

Codex, Claude Code, Cursor는 사용량 집계 방식과 갱신 속도가 서로 다르다. 프로바이더별
일일 상한을 두면 여러 도구를 섞어 쓰는 사용자와 한 도구를 집중해서 쓰는 사용자 중
한쪽이 불리해질 수 있다.

## 결정

- AI 사용 XP는 프로바이더별 주간 토큰 사용량을 마일스톤으로 환산한다.
- 마일스톤 하나는 기본 10 XP이며, 세 프로바이더를 합친 주간 상한은 210 XP다.
- 초기 마일스톤 간격은 Codex 100,000, Claude Code 200,000, Cursor 100,000 토큰이다.
  Claude Code의 로컬 OTel 집계에는 캐시 토큰 비중이 커 별도 간격을 적용한다.
- 한 프로바이더만으로도 남은 주간 상한을 채울 수 있다. 여러 프로바이더가 동시에
  미지급 마일스톤을 보유하면 라운드 로빈으로 지급해 표시 순서의 편향을 피한다.
- 지급 내역은 `xp_events` 원장과 `ai_weekly_xp_milestones`에 함께 기록하고
  프로바이더·주 시작일·마일스톤 번호로 중복 지급을 막는다.
- 쿠폰 부스트는 기존 XP 지급 경로와 동일하게 적용한다. 주간 그래프는 비교 가능한
  기본 AI XP와 210 XP 상한을 표시한다.

## 결과

사용자는 도구 조합과 무관하게 같은 주간 상한을 갖는다. 토큰 집계 특성 차이는
프로바이더별 간격으로 보정할 수 있고, 이후 실제 분포를 보고 간격을 조정할 수 있다.

집계가 늦게 도착해도 해당 주의 마일스톤으로 기록된다. 현재 구현은 앱이 동기화한
현재 주 데이터만 지급하므로 과거 주에 뒤늦게 도착한 데이터의 소급 지급은 하지 않는다.
