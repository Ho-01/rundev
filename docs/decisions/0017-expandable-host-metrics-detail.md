# 0017. 장치 상태 요약과 상세 패널 분리

- 상태: Accepted
- 날짜: 2026-07-30

> 기본 레일과 창 크기 결정은 이후 헤더·좌우 패널 구조와
> [ADR-0038](0038-adaptive-tray-popover-size.md)에서 대체했습니다.

## 맥락

오른쪽 장치 상태 strip의 정사각형 타일은 대표 수치를 빠르게 확인하기에는 충분하지만,
메모리와 저장 장치의 실제 용량이나 네트워크 방향별 속도처럼 원인을 이해하는 데 필요한
값은 제공하지 않는다. 모든 값을 기본 화면에 노출하면 RunDev의 작은 트레이 팝오버가
복잡해진다.

## 결정

- 기본 창은 `340×480`이며 오른쪽 52px 요약 레일에 CPU, 메모리, 온도, 저장 장치,
  배터리, 네트워크의 대표 수치를 표시한다.
- 요약 레일 상단의 `>` 버튼을 누르면 창을 `512×480`으로 확장하고 224px 상세 패널을
  표시한다. 상세 상태에서는 같은 위치에 `<` 버튼만 표시한다.
- 펼침 여부는 프론트엔드 localStorage에 저장하며 도메인 데이터나 SQLite에 기록하지 않는다.
- 기존 실시간 값에 논리 CPU 코어 수, 메모리와 주 저장 장치의 전체·사용·가용 바이트,
  RunDev 실행 후 최고 온도를 추가한다.
- 값은 프로세스 메모리의 최신 스냅샷으로만 유지하고 앱 종료 시 폐기한다.
- 장치명, 볼륨명, 마운트 경로, 네트워크 인터페이스명, IP, MAC, SSID 및 프로세스별
  사용량은 수집하거나 표시하지 않는다.
- 정상·주의·위험을 임의의 색으로 판정하지 않고 측정값과 명시적인 단위만 제공한다.

## 결과

### 장점

- 첫 화면의 정보 밀도를 낮추면서 필요한 사용자는 같은 위치에서 상세 근거를 확인할 수 있다.
- 의미가 불분명한 상태 점이나 임의 임계값 없이 수치를 직접 이해할 수 있다.
- 서버와 영속 저장소를 추가하지 않고 로컬 우선 경계를 유지한다.

### 단점

- 펼칠 때 네이티브 창 크기와 위치를 함께 보정해야 한다.
- macOS와 Windows가 제공하는 온도·배터리 값의 가용성이 다를 수 있다.
- 실행 후 최고 온도는 장기 기록이 아니라 현재 RunDev 프로세스 수명 동안의 값이다.

## 대안

- 기존 정사각형 strip을 항상 유지
- 장치 상태를 별도 모달로 표시
- 임계값에 따라 단일 상태 점의 색상을 변경
