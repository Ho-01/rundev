# Cursor 사용량 연동

## 연결

1. RunDev에서 Cursor 연동을 선택한다.
2. 로컬 로그인 토큰 한 항목을 일시적으로 읽는다는 안내에 동의한다.
3. RunDev가 마스킹된 Cursor 계정을 표시한다.
4. 사용자가 계정을 확인하면 최초 사용량 동기화 후 연동을 활성화한다.

동의 전에는 Cursor 파일을 읽거나 외부 요청을 보내지 않는다. 토큰은 메모리에서
`cursor.com` 요청에만 사용하고 RunDev DB에는 저장하지 않는다.

## 동기화

- 백그라운드 기본 주기: 300초
- RunDev 팝오버를 열 때: 마지막 요청 후 60초가 지났으면 갱신
- 최초 연결: 즉시
- 동시 요청: single-flight

표시 데이터는 오늘의 토큰·포함 사용 가치와 현재 결제 주기의 사용량·한도다.
요청별 상세 이벤트는 안정적인 외부 이벤트 ID가 없으므로 저장하지 않는다.

## 제한

Cursor가 공개하거나 지원하는 API가 아니므로 인증 방식이나 응답 형식이 변경되면
동기화가 중단될 수 있다. 이 경우 RunDev는 마지막 정상 스냅샷을 유지하고 재로그인
또는 형식 변경 상태를 표시한다.
