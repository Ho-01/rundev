# Codex 사용량 연동

## 사용자 흐름

1. RunDev에서 Codex 연동을 선택한다.
2. RunDev가 설치된 Codex CLI의 로그인 계정을 확인한다.
3. 사용자가 계정과 인증 환경을 확인하고 승인한다.
4. Rust 어댑터가 Codex 계정 사용량을 주기적으로 동기화한다.

API 키, Amazon Bedrock 또는 로그아웃 상태는 계정 사용량 연동 대상으로 취급하지
않는다.

## 데이터 범위

RunDev는 계정 단위 일간 토큰 스냅샷, 동기화 시각과 오류 상태만 저장한다.
프롬프트, 응답 및 소스 코드 원문은 읽거나 저장하지 않는다.

## 여러 세션

Codex 연동은 특정 CLI 프로세스가 아니라 확인된 계정 사용량을 조회한다. 동일 계정의
여러 CLI와 IDE 세션은 계정 집계에 포함될 수 있다. 서로 다른 계정이 동시에 사용되는
경우 RunDev가 확인하고 승인한 인증 환경의 계정만 연결한다.

## 상태

- `disconnected`: 사용자가 연동하지 않음
- `syncing`: 최초 계정 집계 대기
- `connected`: 오늘 스냅샷 동기화 성공
- `delayed`: 동기화는 성공했지만 오늘 데이터가 아직 제공되지 않음
- `error`: 로그인, CLI 또는 계정 조회 오류
