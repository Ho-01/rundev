# 제품 로드맵

로드맵은 목표 방향이며 확정 일정이 아니다. 릴리스 범위가 결정되면
`docs/releases/versioning.md`와 `CHANGELOG.md`에 반영한다.

## 0.1.x — 내부 프로토타입

- 트레이 팝오버와 캐릭터 애니메이션
- SQLite 기반 로컬 저장
- Codex와 Claude Code 사용량 연동
- Windows 개발 환경 검증
- macOS universal 테스트 빌드

## 0.2.0 — 활동 및 XP Alpha

- Windows/macOS 활성 앱 분류
- idle, 잠금, 절전 상태 처리
- 활동 세션 원장
- XP 규칙과 캐릭터 레벨
- 개인정보 설정과 데이터 초기화

## 0.3.0 — AI 연동 안정화

- AI 어댑터 상태 진단
- 누락 및 중복 이벤트 처리 강화
- 공급자별 일간·주간 통계
- 여러 CLI와 IDE 세션 검증

## 0.5.0 — 크로스 플랫폼 Beta

- Windows와 macOS 설치·업데이트 흐름
- 코드 서명과 macOS notarization
- 장시간 실행 안정성
- 접근성 및 다중 모니터 검증

## 1.0.0 — 안정 버전

- 공개 배포 품질의 설치 파일
- 호환 가능한 DB migration 정책
- 개인정보 및 장애 복구 문서
- 안정적인 자동 업데이트

## 릴리스 범위 밖

다음 기능은 별도 제품 결정 전까지 구현하지 않는다.

- 로그인과 클라우드 동기화
- 친구, 랭킹, 공유
- 결제와 아이템 상점
- 서버 기반 계정 복구
