# 개인정보 원칙

RunDev는 로컬 우선으로 동작하며 사용자가 명시적으로 연결한 집계 데이터만
저장한다.

## 수집 가능한 정보

- 활성 앱의 분류와 활동 시간
- 마지막 입력 이후 경과 시간
- 화면 잠금 여부
- 연결한 AI 도구의 토큰 합계와 이벤트 식별자
- 어댑터의 마지막 성공 시각과 오류 상태

## 수집하지 않는 정보

- 키 입력과 클립보드 내용
- 창 본문, 화면 캡처, 파일 내용
- 프롬프트와 응답 원문
- 소스 코드
- Claude 또는 Codex 계정 인증 토큰의 복사본

## 저장과 전송

- 앱 데이터는 OS별 RunDev app data 디렉터리의 SQLite에 저장한다.
- Claude Code 사용량은 루프백 주소의 RunDev 수집기로만 전송한다.
- 서버 동기화는 현재 제공하지 않는다.

새로운 수집 항목은 구현 전에 ADR로 목적, 보존 범위, 위험과 대안을 기록한다.
