# 개인정보 원칙

RunDev는 로컬 우선으로 동작하며 사용자가 명시적으로 연결한 집계 데이터만
저장한다.

## 수집 가능한 정보

- 활성 앱의 분류와 활동 시간
- 마지막 입력 이후 경과 시간
- 화면 잠금 여부
- 연결한 AI 도구의 토큰 합계, 이벤트 식별자와 해시된 세션 키
- 어댑터의 마지막 성공 시각과 오류 상태

호스트 지표(CPU·메모리·온도·디스크·배터리·네트워크 활동)는 팝오버 표시용으로만
메모리에 두고 SQLite에 저장하지 않는다. 자세한 범위는 ADR 0014를 본다.

## 수집하지 않는 정보

- 키 입력과 클립보드 내용
- 창 본문, 화면 캡처, 파일 내용
- 프롬프트와 응답 원문
- 소스 코드
- Claude 또는 Codex 계정 인증 토큰의 복사본
- Claude 원본 세션 ID

## 저장과 전송

- 앱 데이터는 OS별 RunDev app data 디렉터리의 SQLite에 저장한다.
- Claude Code 사용량은 루프백 주소의 RunDev 수집기로만 전송한다.
- 서버 동기화는 현재 제공하지 않는다.
- RunDev가 활동 데이터를 외부로 수집하는 것은 아니지만, 업데이트 확인을 위해
  GitHub Releases에 네트워크 요청이 발생한다. 요청에는 앱 버전과 OS/CPU
  대상이 실릴 수 있고, IP 주소와 User-Agent는 GitHub/CDN 로그에 남을 수 있다.
  설치 파일 다운로드도 같은 Release 호스트에서 이뤄진다.
- 호스트 지표의 네트워크 활동은 기기 안에서만 집계하며 외부로 보내지 않는다.

새로운 수집 항목은 구현 전에 ADR로 목적, 보존 범위, 위험과 대안을 기록한다.
