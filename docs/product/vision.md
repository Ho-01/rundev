# 제품 비전

RunDev는 개발 활동을 방해하지 않고 곁에서 보여주는 로컬 우선 데스크톱
컴패니언이다. 개발 시간을 숫자로만 압박하기보다 작은 캐릭터의 성장과 상태로
표현한다.

## 지향점

- Windows와 macOS에서 가볍게 상주한다.
- 사용자가 앱을 열지 않아도 활동 집계와 캐릭터 상태가 유지된다.
- AI 도구별 사용량을 한 화면에서 이해할 수 있다.
- 기본 기능은 로그인과 서버 없이 동작한다.
- 수집 범위와 출처를 사용자가 이해하고 직접 제어할 수 있다.

## 하지 않는 것

- 키 입력, 프롬프트, 응답, 소스 코드 원문 수집
- 생산성 점수로 사용자를 감시하거나 평가
- 동의 없는 계정 및 클라우드 연동
- 로컬 기능에 불필요한 서버 의존성 추가

## 성공 기준

사용자는 설치 후 몇 분 안에 연동 상태를 이해하고, 하루 동안 RunDev를 의식적으로
관리하지 않아도 정확한 로컬 요약을 확인할 수 있어야 한다.
